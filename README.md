<h2 id="about">About</h2>
<p>
  This repository is a collection of hands-on laboratory work. Each activity lives in its
  own folder, numbered in the order it was taken in class, so the full learning path from
  fundamentals to advanced algorithmic topics can be followed from top to bottom.
